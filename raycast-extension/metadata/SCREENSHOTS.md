# Screenshots to take before submitting

These need Raycast running, so they weren't made yet. Delete this file when the PNGs are in; the store only wants the PNGs here.

How: run `npm run dev`, open Raycast's **Capture Window** command in development mode, choose "Save to Metadata". 2000 x 1250 PNG, one consistent wallpaper with good contrast, only this extension in view, no other apps or personal data, one theme (not light and dark mixed). Glideball must be running with "Allow Raycast and scripts" on, and a Kensington trackball connected so the status looks real.

Name them `glideball-1.png` to `glideball-6.png`. Three to six is right; this is the order I'd use:

1. **Glideball Status**, the whole list (state, trackball, scroll mode, pointer speed, today's numbers).
2. **Set Scroll Mode**, with Flywheel marked Current.
3. **Set Pointer Speed**, with a speed typed in the search field so the "Typed" row shows.
4. **Root search** with "glideball" typed, showing the command list.
5. **Not set up yet**: Set Scroll Mode with the switch off, showing the "Glideball isn't listening to Raycast yet" message (shows the first-run help).
6. **Toggle Glideball** result: the "Glideball paused" HUD over the desktop (optional).
