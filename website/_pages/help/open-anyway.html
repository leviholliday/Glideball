Why macOS shows the warning

The first time you open Glideball, macOS says Apple could not verify that it's free of malware. That's expected. Apple checks apps it has notarized, and notarizing needs a paid Apple developer account. I'm one student making a free app, so I don't have one. Glideball is still signed, and all of its code is public on GitHub for anyone to read.

The warning doesn't mean anything was found wrong. It means Apple hasn't looked.

Open it, step by step

  1. Open Glideball from Applications

    Double-click it. macOS shows “Glideball” Not Opened.

  2. Click Done

    Not Move to Trash.

  3. Open System Settings › Privacy & Security

    Scroll down to the Security section. You'll see a line saying Glideball was blocked.

  4. Click Open Anyway

    Confirm with your Mac password or Touch ID, then click Open Anyway once more if asked. Glideball opens.

Don't see Open Anyway? Try opening Glideball again first, then go straight back to Privacy & Security. macOS only shows the button for a while after a blocked launch.

Control-click › Open used to skip all this. Since macOS 15 it doesn't, so Open Anyway is the way.

After that

You won't see the warning again, and updates don't ask. Glideball only installs an update if it's signed with the same certificate as the copy you already have, so a changed download gets refused.
