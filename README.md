# Glideball updates for older copies

Copies of Glideball up to 2.10 beta 55 look here for updates, so new releases are copied here too.
Glideball's source isn't here, and the main home for releases is
[glideball-releases](https://github.com/leviholliday/glideball-releases).

- Download Glideball: https://glideball.app/download/
- What's new: https://glideball.app/changelog/
- Feedback, bugs and questions: https://glideball.app/feedback/

Glideball only installs an update signed by its developer.

Glideball 2.9.1 and earlier were released under the MIT licence, and those releases stay under it.
